# My-ToDoList
To-Do List App
This is a simple mini project called To-Do List App. It is made for students and beginners to understand the basic structure of a web application using HTML. The app helps users write down their daily tasks and manage them easily.

About the Project
The main purpose of this project is to create a task list where users can keep track of the work they need to do. It is a very useful project for learning and practicing basic web development concepts.

Features:
Add tasks
View tasks
Mark tasks as completed
Delete tasks
Easy and simple design

Technologies Used:
HTML
Why I Made This Project
I made this project to improve my web development skills and to understand how a simple to-do list application works. This project is helpful for beginners who want to start learning front-end development.

How to Run the Project:
Download or clone the project.
Open the project folder.
Open the index.html file in any web browser.
